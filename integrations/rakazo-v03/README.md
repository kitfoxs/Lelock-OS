# Lelock direct character-computer sidecar

This directory is installed in two places by the handoff: as source in Lelock,
and under `integrations/lelock-v03` in the actual Rakazo checkout so `entry.mjs`
can import its real factory. Read the packet's RAKAZO_DIRECT_ACTOR.md.
`service.ts` is first-party code; `dist/service.js` is generated by its tsconfig.
`upstream-conformance.ts` is checked separately against actual Rakazo dependencies.
`node --test tests/direct.test.mjs` uses deterministic provider doubles, not Docker.
No Pi/model runtime is instantiated here. The selected main character calls the
computer through this sidecar; optional helpers keep their own actor IDs.
