# Contributing

Keep changes bounded and testable. The core is an experience/control layer around Hermes, not a second agent framework. Preserve source-linked memory, explicit approvals, scope separation, honest failures, and the distinction between fixtures and live evidence.

Run `python3 scripts/verify.py` after changes. Runtime adapters additionally require the relevant actual service/model gates. Add a focused regression for a discovered defect. Do not weaken assertions, hardcode synthetic answers into production or add unrestricted tools to make a demo smoother.

Use synthetic test data and original/licensed personas. No private Palace records, credentials, real relationship histories or copyrighted character assets without appropriate rights. Retain upstream notices. Public issue/report channels and release policy should be established by the maintainer rather than invented in code.
