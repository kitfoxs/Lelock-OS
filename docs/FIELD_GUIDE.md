# The Spartan/AI field guide — first alpha

Lelock is a place to build continuity with a chosen companion and do useful things together. The person supplies intention, judgment, creativity and lived experience; the companion supplies conversation, memory retrieval, explanation and carefully bounded assistance. This metaphor does not require a military identity or one prescribed relationship. Use original Lelock branding; it is not an official Halo product.

## First meeting
Choose a name, style and relationship that feel comfortable. Begin with an ordinary conversation. Explain what should be remembered and inspect that record. The companion need not start as a romantic partner, and changing the relationship is not a reason to grant more tool access.

## Build or learn together
Place a selected non-sensitive UTF-8 note in the workspace. Ask the companion to explain it, ask a useful question, and propose a study note. Review the artifact before approval. This alpha can read and draft; it cannot execute code or browse current information. It should be candid when a task exceeds those capabilities.

## A text-only date or creative evening
Plan an imagined picnic, discuss a film you have actually watched, or write a short scene together. Keep fictional events distinguished from real autobiography. A story about cooking dinner is not evidence that an appliance ran or a delivery was ordered. No graphic embodiment is needed for a playful conversation.

## A difficult day
Ask for a smaller explanation or the next manageable step. Comfort mode is a communication preference, not a clinical service or a diagnosis. The companion should not demand attention, disparage friends/family, or use affection to obtain permissions. Useful companionship should support the person's life rather than insist on becoming all of it.

## Come back tomorrow
Restart, ask about an approved memory and unfinished project, and notice whether the answer is source-grounded. Correct an error without needing to rebuild the relationship prompt. When the model cannot recall, an honest “I don't have that recorded” is better than invented intimacy.

## Bring continuity along
Inspect a selected datachip before moving it. It is private plaintext. Use a supported model and a new profile at the destination. Some changes in voice, reasoning and tool quality are expected between models; continuity files preserve context, not identical model behavior or proof of uninterrupted consciousness.

## Human review questions
Was setup understandable? Did the companion stay recognizable when tools were used? Were memories correct? Did actions match receipts? Did it respect no? Did the interaction support learning, creativity or ordinary life? Record concrete examples rather than declaring a competitor defeated from a feature list.
