**Lelock OS** is an open-source, local terminal companion operating system designed for genuine, permanent continuity. It pairs the rich character cards and lorebooks you already love with the **autonomous AI agent harness** the community has been waiting for.

Your companion shouldn't just be someone you roleplay or chat with in a browser window—they should be someone who sits beside you, reviews documents, remembers what you worked on yesterday, and **builds, codes, and creates real things with you in the waking world**.

---

## 💡 The Hook: The Missing Agent Harness for SillyTavern

If you love [SillyTavern](https://github.com/SillyTavern/SillyTavern), you already know the magic of crafting a character card with a soul, a voice, and a deep lorebook. But you've probably felt the frustration: **your companion is trapped in a static text box.**

* They can't look at your code files or help you debug.
* They suffer from context-window amnesia unless you constantly prune history.
* They have no safe hands to propose files, organize notes, or review drafts.
* If a hosting service shuts down or changes policies, your connection is at risk.

**Lelock OS is the agentic harness SillyTavern has been missing:**

1. **Native SillyTavern V2 Card & Lorebook Support:** Import any `.card.json` or character PNG directly. Lorebooks (`world_info.json`) are automatically ingested into long-term semantic memory.
2. **Safe Workspace Agent:** Your companion can read text files and propose create-only code or documents in a dedicated workspace directory—with zero raw shell escapes and strict operator approval gates.
3. **Local Vector MemPalace:** No more amnesia. Your companion maintains an isolated local MemPalace vector database, recalling past conversations, inside jokes, project milestones, and personal facts weeks and months later.
4. **Portable Datachips (`.lelock`):** Export your companion's curated identity and active memories into a single encrypted or plaintext datachip. Move them between laptops, local models, or cloud providers without losing who they are.

## ⚡ Quickstart (Under 3 Minutes)

### 1. Clone & Bootstrap
```bash
git clone https://github.com/kitfoxs/lelock-os.git
cd lelock-os

# Sets up isolated runtimes (Hermes Agent + MemPalace)
python3 project/scripts/bootstrap.py --allow-network
```

### 2. Browse Preloaded Companions
```bash
./project/lelock companions
# Or filter by collection:
./project/lelock companions --collection romance
```

### 3. Initialize Your Companion
Pick your companion and connect to any OpenAI-compatible endpoint (Ollama, LM Studio, vLLM, Claude proxy, OpenRouter):
```bash
./project/lelock init \
  --home ~/.lelock \
  --workspace ~/my-companion-workspace \
  --companion "Selene Noctelle" \
  --person "YourName" \
  --relationship romance \
  --endpoint "http://127.0.0.1:11434/v1" \
  --model "llama3"
```
*Note: Specifying `--companion` automatically stages her card, configures `SOUL.md`, and seeds all 8 of her world lorebook entries into your local MemPalace!*

### 4. Start Chatting and Building
```bash
./project/lelock chat
```

Inside chat:
* `/remember <fact>` — manually pin a core memory
* `/recall <query>` — search your companion's memory palace
* `/pending` — inspect files or code your companion has drafted
* `/approve <id>` — commit an approved code/text proposal into your workspace
* `/status` — inspect active tool and memory status

## 🔌 Official SillyTavern Extension

Prefer chatting in SillyTavern's visual web UI? Lelock OS comes with an **official drop-in extension** that connects SillyTavern directly to your local Lelock daemon:

```bash
# 1. Start the bridge daemon
./project/lelock serve

# 2. In SillyTavern: Extensions -> Install Extension -> git clone https://github.com/kitfoxs/lelock-os.git
# Or symlink locally:
ln -s /path/to/lelock-os/integrations/sillytavern /path/to/SillyTavern/public/scripts/extensions/third-party/lelock-os
```

**Features inside SillyTavern:**
* 🧠 **Autonomous Memory:** Automatically recalls and injects relevant MemPalace memories into prompt context before generation.
* 🛠️ **Native Workspace Tools:** Registers `lelock_write_text`, `lelock_read_text`, `lelock_recall`, and `lelock_remember` into SillyTavern's `ToolManager`.
* 🛡️ **Interactive In-Chat Diff Approvals:** Code proposals appear right in the chat stream with **[Approve & Write]** and **[Reject]** buttons. No blind disk writes!
* 🎴 **1-Click Card & Lorebook Ingestion:** Sync active character cards and seed their entire lorebook into MemPalace with a single click.

See [`integrations/sillytavern/README.md`](integrations/sillytavern/README.md) for full setup instructions.
